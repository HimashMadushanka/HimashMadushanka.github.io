# Himash Madushanka — Data Science Portfolio

A responsive portfolio showcasing my data science projects, skills, education, experience, achievements, and community involvement.

**Live portfolio:** [himashmadushanka.github.io](https://himashmadushanka.github.io/)

## Highlights

- Featured projects with search and category filters
- Dark and light themes
- Achievements and volunteering photo galleries
- Downloadable resume and contact form

## Built with

HTML, CSS, JavaScript, and JSON. The site is hosted on GitHub Pages.

## Run locally

Requires [Node.js](https://nodejs.org/) (no additional packages needed).

```bash
npm run dev
```

Open [http://localhost:8000](http://localhost:8000) in your browser. Press `Ctrl+C` in the terminal to stop the server. To use a different port, set the `PORT` environment variable before starting the server.
